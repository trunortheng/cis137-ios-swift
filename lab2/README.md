## 🎯 About the Project

**What the Flip** is a sleek, modern iOS mobile game designed with precision. Built from the ground up using **Swift** and **SwiftUI**, this application showcases clean architectural patterns, reactive state management, and smooth, fluid animations characteristic of a polished native iOS experience. 

Developed as part of coursework (`CIS137` - Lab 2), this project highlights best practices in modern mobile app design, state persistence, and interactive UI components.
